# Hit_ANZ — 装甲板波形上位机（波形 + 冲量特征 + 落点定位 + 在线调参）

接收装甲板经 USART1（**921600 8N1**）发来的 `WAV1` 冻结窗波形帧，
绘制四通道 hp 波形；**「落点分析」页签**按帧计算每传感器峰值/冲量/均方根，
并用 EMA（实验模态）传递矩阵法反演击打位置、给出残差热图与相对力历史，
同时始终显示加权质心作为对照。右侧嵌套选项卡内还有 **击打参数**（在线调
P01/P03/P04/P05/P26/P27、可存档 Flash）与 **参照替换**（把某次记录的击打
写成板子的形状参照，立即生效）。协议权威见
[`../Docs/USART1波形数据帧格式.md`](../Docs/USART1波形数据帧格式.md)（HCMD 命令见其 §8）。

## 安装（一次）

```bash
# 国内网络加清华镜像；装 PySide6-Essentials 即可，不必装全量 PySide6
# （全量还会拉 Addons/WebEngine/Pdf，多 ~300MB，本项目用不到）
py -3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ^
    PySide6-Essentials pyqtgraph pyserial numpy scipy
```

永久换源（只配一次，之后 pip 全部走镜像）：
`py -3 -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`
（还原：`py -3 -m pip config unset global.index-url`）。也可用 `uv pip install`（并行下载，通常再快数倍）。

已装可跳过（`py -3 -m pip list` 检查）。Windows x86-64，Python 3.13 已验证。

目标机**不通外网**时走离线安装：仓库根目录的 `wheels/`（本机 `pip download` 生成的 7 个轮子，131MB，不入库）
整包拷到目标机后 `py -3 -m pip install --no-index --find-links <wheels路径> PySide6-Essentials pyqtgraph pyserial numpy scipy`，
详见 `wheels/安装说明.txt`。要求目标机同为 CPython 3.13 x86-64（numpy/scipy 轮子按 cp313 打包）。

## 使用

| 操作 | 说明 |
|---|---|
| 连接串口 | 先在右侧选端口（点「刷新」重新枚举）→ 波特率保持 921600 → 工具栏「连接串口」 |
| 回放文件… | 选择原始抓包 `.bin`，按 ~92KB/s 模拟串口节奏回放（**无硬件时的验证路径**） |
| 导出原始流… | 保存本次会话收到的全部原始字节（含文本行），便于离线复查 |
| 历史帧下拉框 | 浏览最近的确认帧（最多 200 帧），选中即回看（两个页签同步） |
| 页签「波形」 | 黄虚线 = 触发样本（索引 `n−1−P22`）；灰点线 = 窗内 `|hp_sum|` 峰值（`pk_idx`）；四个子图 X 轴联动缩放 |
| 页签「落点分析」 | 俯视图（板面/传感器/形心/残差热图/落点/历史点）+ 右侧嵌套选项卡：定位标定 / 击打参数 / 参照替换，见下两节 |
| 日志面板 | 固件文本行（启动横幅/[HIT]/[CONF]）+ 帧摘要（蓝）+ 跳号/CRC 告警（红） |
| 状态栏 | 字节 / 帧 / CRC 错 / 重同步 / 文本行计数 |

**数据不是连续流**：固件每确认一次击打发一帧（≥200 ms 间隔），所以波形区是
「最新一帧 + 历史回看」，不是滚动示波器。

## 落点分析（EMA 传递矩阵法）

每帧按传感器 a..d 计算三个特征：

| 特征 | 定义 | 单位 |
|---|---|---|
| 峰值 peak | 固件算好的各通道窗内 max\|hp\|（帧头 `peak_ch`） | counts |
| 冲量 impulse | Σ\|hp\|·Δt，Δt = 1/3906.25 s | **counts·s**（无量纲口径） |
| 均方根 rms | √(mean(hp²)) | counts |

**落点**按用户指定的实验模态方法反演：把「冲击点 → 四路支撑力」当作 LTI 系统，
标定得到传递函数矩阵 H_ij(ω)，实测帧做 FFT 后逐频点单位范数归一化，对网格签名
复数双线性插值到 2 mm 细网格，取残差 `e(x,y) = Σ_ω(1−|h^H r|²)` 的最小点。
力历史 `ŝ(ω)=h_p^H y(ω)` 经 irfft 得到，其冲量/RMS 为**相对量**（counts 量纲）。
加权质心（特征源可选冲量/峰值/RMS）始终同屏显示作对照。

### 标定流程（按钮驱动，一次即可）

1. 设置里确认板面 AB/AD 与传感器位置；采样率/窗长由帧头决定（n=128）。
2. 「落点分析」页签 → 标定区：网格行×列（默认 5×5，四角即板四角）、每点敲击
   次数（默认 3）、反演频带（默认 60–1500 Hz）。
3. 点「开始标定」，俯视图出现黄色圆环标出**下一个待敲点**；用冲击锤（或同一
   支笔/螺丝刀以相近方式）在该点敲击，画面每收到一帧就记一次，进度列表实时
   显示 `n/次数 q=一致性`。
4. 「跳过此点」略过难以敲击的位置（至少保留 2×2 有效点）；「重敲此点」清空当前
   点重来；全部完成后点「完成并保存」写入 npz（默认
   `Hit_ANZ/calib/transfer.npz`，路径随设置保存，可用「选择…」换文件）。
5. 之后每次连接/回放自动载入，新帧直接给出 EMA 落点 + 残差热图 + 历史点。

> 一致性 q 接近 1 表示同点多次敲击的传递签名一致；明显偏低（<0.8）建议重敲该点，
> 通常是敲击位置偏移或力度/工具差异过大。标定与实测必须使用同一 P21/P22，
> 因为签名以触发样本为时间原点对齐。

### 限制（与数据本身有关）

- 每帧 32.8 ms、Δf≈30.5 Hz、Nyquist≈1953 Hz：高于 ~2 kHz 的板模态不可观测，
  定位主要依赖低频空间衰减与低阶模态。频带可在设置里收缩。
- 力历史是相对量（相对标定敲击），不是牛顿；冲量沿用已定的无量纲 counts·s。
- 改动板面几何/传感器位置后标定集自动判为不一致（提示重新标定），不会悄悄给
  出错位结果。
- 细网格覆盖整板，结果天然在板内；仍保留「越界 → 形心连线与边界交点」的防御
  性显示（正常不会触发）。通道映射被改坏时落点分析降级为提示，不会崩溃。

## 在线命令（HCMD，需串口连接——回放模式不发送）

「落点分析」页右侧嵌套选项卡，帧格式与 ACK 语法权威见
`../Docs/USART1波形数据帧格式.md` §8。**一次一令**：板子 Flash 擦写停取指
~25–31 ms，发完一条等回执（2 s 超时）再发下一条；所有 ACK 同时出现在日志面板。

### 击打参数

| 参数 | 名称 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| P01 | 基线 EMA 移位 | 8–16 | 13 | 改后热身时长重算（5×2^s_bl 样本）；紫闪相位本 boot 不跟随 |
| P03 | 触发最小持续 | 1–64 样本 | 4 | 1 样本 = 256 µs |
| P04 | 触发阈值 | 1000–2000000 counts | 25000 | 滑动窗幅度触发 |
| P05 | 不应期 | 50–1000 ms | 200 | 下界 50 保 WAV1 + 落盘窗口 |
| P26 | 沉降门控 | 1–512 样本 | 64 | 不应期后连续低于阈值才重新武装 |
| P27 | 相关度阈值 | 0–1024 q10 | 609 | **0 = 只统计不判拒**（重采分布用）；收紧前先在台架看 corr 分布 |

按钮：**读取当前值**（GET_PARAMS）／**写入（生效）**（SET_PARAMS，只改 RAM，
掉电丢失）／**存档到 Flash**（先同步参数再 SAVE_PARAMS，双槽断电安全）／
**恢复默认**（仅 6 字段回默认，RAM）。P21/P22 **不开放**（改窗长即毁参照与
标定签名）。参数不保存到本机 config.json——板子才是真值，重连后按「读取」。

### 参照替换

历史帧下拉框选一帧 → 「写入参照（立即生效）」→ 确认 → 板子把该帧四通道 hp
求和窗写入 Flash 页 63 并置位「本上电已训练」，**立即参与相关度判定**（基线
热身 5τ 内仍不判拒）。红字警告：type=2 曾被相关度拒绝、峰值贴窗边、窗长 ≠128
的帧通常不适合。**坏参照会把真实击打判拒，恢复 = 再推一帧好参照**；清空参照
需调试器（命令通道不提供）。锁帧确认中/自检运行中写入会收到 `err ref busy`。

## 设置（右侧面板，改动即存 `config.json`，重启还原）

- **串口**：端口、波特率
- **击打面几何**：AB（横）/ AD（纵）长度，mm
- **传感器位置** a/b/c/d：默认跟随矩形四角（原点 = a 角，x 沿 AB，y 沿 AD）；
  取消勾选后可手动摆放
- **通道 → 传感器映射**：ch1..ch4 → a/b/c/d（波形左侧标签同步变化）
- **P21/P22**：仅用于触发样本标记位置（默认 64/64）
- **落点分析**（第二页签内）：质心特征源、标定网格行×列、每点敲击次数、
  反演频带、标定集路径
- **击打参数/参照替换**：不落 config.json——板子是唯一真值（每次重连「读取当前值」）

`config.json` 不入库（`.gitignore`），每台机器独立保存；测试可用环境变量
`HIT_ANZ_CONFIG` 指向别处。

## 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 打开串口失败 | 端口被别的终端占用（串口独占）；关掉再点「刷新」 |
| 全是乱码、无帧 | 波特率不是 921600（固件默认）；或 TX/RX 未交叉 |
| 有文本行无帧 | 装甲板还没完成热身后的首次训练；敲击需被接受一次后才开始发波形帧 |
| CRC 错计数增长 | 串口线过长/干扰导致丢字节（偶发可忽略，持续需查线）。坏帧区间内的字节按二进制垃圾处理：日志不刷屏，但紧邻坏帧的少量文本行会被丢弃（界面有红色 CRC 告警） |
| trig_id 跳号 | 下位机冻结中止（不发帧，正常）或下位机 DMA 发送丢弃（见协议文档 §6） |
| 落点始终「未标定」 | 还没完成标定/没找到 npz：看「数据集」路径，或用「选择…」指定 |
| 落点提示「几何不一致」 | 板面 AB/AD 与标定时不同，重新标定（或把几何改回） |
| 标定一致性 q 很低 | 同点敲击位置/工具差异大：对该点「重敲此点」，尽量垂直敲、同一支工具 |
| 落点总在板中心附近 | 标定数据太“平”（例如所有点用同一签名造出来的测试集）；按真实网格重标 |
| 命令按钮全灰 | 只有串口连接后才使能（回放模式不发送）；连上后等「数据源已打开」日志 |
| 命令超时 / 无回执 | 板子固件不含 HCMD（旧固件）；或上一条 Flash 操作未完成——等 2 s 超时后重发 |
| 收到 `err save busy` / `err ref busy` | 锁帧确认中或自检运行中：Flash 擦写会打断采样，稍后重试 |
| 收到 `err ref len=N win=128` | 所选帧窗长与板子当前 P21+P22 不一致（改过窗长或旧固件录的帧） |
| 推了坏参照、击打被拒 | 再选一帧**被接受且峰值不贴边**的帧重新写入；清空参照需调试器 |
